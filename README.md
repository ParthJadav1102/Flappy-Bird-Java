# Flappy-Bird-Java
🔥Better understand Java Swing Concept and use also OOPs concept
The Flappy Bird Clone is a simple 2D game built using Java and Swing/JavaFX. The player controls a bird that must navigate through a series of obstacles (pipes) by tapping or pressing a key to flap and avoid collisions. The game continuously moves forward, and the player earns points by successfully passing through gaps between the pipes.
